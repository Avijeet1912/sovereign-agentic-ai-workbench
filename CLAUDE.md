# SIH MVP — Sovereign Agentic AI Workbench

## Project Goal

Build the MVP/prototype for our SIH project.

## Important Instructions

- This is an MVP, not a production-scale application.
- Keep the implementation simple and practical.
- Prioritize working features over unnecessary complexity.
- Do not add unnecessary libraries or technologies.
- Keep the code organized and understandable.
- Explain major changes before making them.
- Test features after implementing them.
- Do not expose API keys or secrets.
- Never modify or delete important existing work without explaining why.

## Development Rules

- Build one feature at a time.
- After completing a meaningful feature, verify that it works.
- Keep the project runnable at every major checkpoint.
- Use Git commits as checkpoints.
- Do NOT automatically push to GitHub unless explicitly asked.
